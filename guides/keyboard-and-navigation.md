# Keyboard and navigation

## Global

- `Ctrl+K` or `Cmd+K`: open the command palette.
- `Escape`: close the current menu, panel, or dialog when supported.
- `Tab` and `Shift+Tab`: move between interactive groups.

## Editor

- `Ctrl+F` or `Cmd+F`: find and replace.
- `Ctrl+B` or `Cmd+B`: bold.
- `Ctrl+I` or `Cmd+I`: italic.
- `Ctrl+U` or `Cmd+U`: underline where supported.
- `Ctrl+Z` or `Cmd+Z`: undo.
- `Ctrl+Shift+Z` or `Cmd+Shift+Z`: redo.
- `Ctrl+Shift+V` or `Cmd+Shift+V`: paste as plain text where supported.

Use visible tooltips and the in-product Help panel as the current reference. Browser, operating-system, editor mode, and content type can affect shortcuts.

## Accessibility

Prefer standard keyboard navigation and semantic controls. Keep focus visible. When a panel closes, confirm focus returns to a sensible control. If a shortcut conflicts with assistive technology or the browser, use the visible interface control instead.
