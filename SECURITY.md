# Security

## Report a security issue

Do not open a public issue for a suspected vulnerability, exposed credential, private link, or customer data. Contact [DotMD Customer Care](https://dotmd.co/contact) and clearly mark the report as a security issue.

Include a concise impact description and safe reproduction steps. Do not include real customer content or active credentials.

## Scope of this repository

This repository contains documentation and AI instruction files, not the DotMD service source. Documentation mistakes that could cause unsafe access, publishing, data loss, or secret exposure are still worth reporting privately.

## Credential safety

DotMD credentials and MCP API keys must never be committed here. If a credential is exposed, revoke it immediately in DotMD or the relevant provider before reporting it.
