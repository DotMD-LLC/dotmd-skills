# Contributing

Thank you for improving DotMD's public guides and AI skills.

## Good contributions

- Correct unclear or outdated public instructions.
- Add a safe workflow example.
- Improve accessibility and plain language.
- Add client-neutral guidance for a released capability.

## Never submit

- DotMD application source or copied private-repository content;
- internal architecture, operations, incident, roadmap, or customer material;
- credentials, tokens, private links, account details, or screenshots with private data;
- claims about unreleased or unverified features.

## Pull request checklist

- [ ] The content describes user-visible behavior.
- [ ] Links are relative or point to an intentional public destination.
- [ ] Instructions preserve least privilege and explicit publishing consent.
- [ ] No secret, customer, local-path, or private-repository data is present.
- [ ] Skill files contain valid `name` and `description` frontmatter.
- [ ] DotMD uses the correct brand casing.
